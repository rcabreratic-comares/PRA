# Programas de Refuerzo · IES Marqués de Comares

Aplicación estática para preparar medidas de los Programas de Refuerzo de los Aprendizajes (PRA) y copiarlas en Séneca.

## Uso

Abre `index.html` en un navegador. Selecciona las tipologías, revisa las medidas sugeridas y añade las que necesites. Después puedes copiar cada apartado, copiar el informe completo, imprimirlo o guardarlo como texto.

No necesita instalación ni servidor. La página carga Tailwind CSS, Google Fonts y Font Awesome desde sus CDN, por lo que algunas mejoras visuales requieren conexión a internet.

## Privacidad

Los datos escritos en el formulario se procesan en el navegador. No se envían a GitHub ni se incluyen en el código publicado. El botón **Guardar borrador** almacena el borrador en el almacenamiento local del navegador de ese dispositivo; evita introducir datos personales innecesarios y sigue las normas de protección de datos del centro.

Si el repositorio es público, el código y el logotipo incluidos en él serán visibles públicamente. La página publicada mediante GitHub Pages también será accesible públicamente; no introduzcas información real del alumnado en enlaces, archivos o capturas compartidos.

El pie de página incluye un enlace de contacto a Twitter: [@rcabreratic](https://twitter.com/rcabreratic).

## Publicación en GitHub Pages

1. El repositorio público utilizado para esta aplicación es `rcabreratic-comares/PRA`.
2. Sube `index.html`, `README.md`, `.gitignore`, `Logo_Comares_Color_Horizontal (1).png` y `nombreserendipia.jpg` a la rama `main`.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Cuando finalice el despliegue, abre `https://rcabreratic-comares.github.io/PRA/`.
